# 《避难所：余烬纪元》H5 视觉与交互规范

## 视觉基线

H5 版本沿用仓库现有 `assets/cover_art.png`：深青黑的晦城、防空洞暖色入口与橙色余烬是唯一主视觉。界面采用“防空洞指挥终端”方向，不新增营销式标语、徽章、虚假指标或默认卡片网格。

- 背景：真实深青黑 `#071014`，不是系统灰或暖灰。
- 主强调：余烬橙 `#d8873f`；信息强调：旧纸金 `#dfc36f`。
- 正文：近白 `#f4f5ef`；主按钮前景色独立由 `theme.on_primary` 配置，封面固定使用白色按钮文字。
- 字体：优先苹方、微软雅黑与 Noto CJK，所有游戏文字由代码渲染。
- 形状：主入口与关键选择延续平行四边形；正文区域使用开放面板和细边框，避免层层嵌套卡片。

## 首屏文案锁

封面仅允许出现以下代码原生文字：

1. `避难所`
2. `余烬纪元`
3. `新的游戏`
4. `游玩存档`
5. `多人游戏`

不添加首页简介、小字说明、版本号、状态徽章或图标行。

## 桌面与横屏结构

桌面指挥台采用三栏：左侧所长与避难所资源，中间当前任务和行动记录，右侧行动指令。顶栏只显示时间、模式、当前所长与主线进度。所有二级操作替换当前 Laya 页面或进入页面栈，不使用浏览器弹窗。

## 手机竖屏结构

手机使用纵向任务流：顶栏展示时间和当前所长，中部优先展示主线任务、两条危险资源和最近行动，底部固定五个入口“指挥台、剧情、探索、经营、物资”。复杂选项进入全高页面，按钮单列排列，最小触控高度为 56 逻辑像素。

## 组件族

- `GameButton`：主按钮、次按钮、危险按钮、禁用按钮四种状态。
- `StatusMeter`：生命、饥饿、耐久、群体饥饿四种语义。
- `CommandPanel`：桌面行动分组与手机操作页共用数据源。
- `NarrativePage`：剧情、探索事件、教程和结局共用可滚动正文。
- `ChoiceList`：配置驱动的可用、锁定和选中状态。
- `BottomNavigation`：仅在移动布局显示，保持五个稳定入口。

## 动效与性能

页面只使用短距离淡入与位移，封面采用极慢的镜头漂移。系统开启“减少动态效果”时停用非必要动效。标签页失焦后切换 LayaAir 慢帧模式；没有角色物理与实时战斗循环，领域状态只在用户操作时结算。

## 资产边界

这是文字剧情游戏，没有角色移动、碰撞、地形或拾取物，因此无需伪造角色精灵和瓦片。现有正式封面承担场景氛围，HUD、按钮、状态条和全部文字保持代码原生。当前会话缺少内置图像生成工具，后续若增加伙伴立绘或章节场景，应按独立可替换资源接入，不改变领域逻辑。
