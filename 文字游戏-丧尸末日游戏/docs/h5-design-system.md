# 《避难所·往昔》H5 视觉与交互规范

## 视觉基线

H5 版本沿用 2K 主视觉 `assets/cover_art_2k.png`：深青黑的晦城、防空洞暖色入口与橙色余烬是唯一主视觉。界面采用“防空洞指挥终端”方向，不新增营销式标语、徽章、虚假指标或默认卡片网格。

- 背景：真实深青黑 `#071014`，不是系统灰或暖灰。
- 主强调：余烬橙 `#d8873f`；信息强调：旧纸金 `#dfc36f`。
- 正文：近白 `#f4f5ef`；主按钮前景色独立由 `theme.on_primary` 配置，封面固定使用白色按钮文字。
- 字体：优先苹方、微软雅黑与 Noto CJK，所有游戏文字由代码渲染。
- 形状：主入口与关键选择延续平行四边形；正文区域使用开放面板和细边框，避免层层嵌套卡片。

## 首屏文案锁

封面仅允许出现以下代码原生文字：

1. `避难所`
2. `往昔`
3. `新的游戏`
4. `游玩存档`
5. `多人游戏`
6. `剧情模式`
7. `鸣谢`
8. `退出`

不添加常驻首页简介、小字说明、版本号、状态徽章或图标行。桌面菜单仅在鼠标悬停满 800ms 后显示独立小窗简介，移出立即隐藏；手机不显示悬停小窗。

## 桌面与横屏结构

桌面封面菜单使用 PNG 平行四边形皮肤，位于左侧并向右下逐项错位，退出永远最低。宽桌面指挥台采用三栏：左侧所长与避难所资源，中间通讯记录或剧情任务，右侧行动指令；标题栏右侧始终提供设置，剧情模式再增加剧情入口。二级页面覆盖在一级页面上，三级以此类推；返回只销毁最上层，不使用浏览器弹窗。安全区内可用宽度低于配置阈值时，桌面自动降级为紧凑结构，不强行压缩三栏。

## 手机竖屏结构

手机封面菜单是底部居中、宽度一致的长方形单列。游戏内使用纵向任务流：顶栏展示时间、当前所长和设置键，中部展示四条风险资源与核心行动。普通单人和多人模式不显示剧情任务卡，底部为“指挥台、探索、经营、物资”四项；剧情模式显示任务卡，并在底部增加“剧情模式”形成五项。底栏图标置于文字上方，避免窄屏裁字。复杂选项进入可滚动页面，底部操作区保留安全区间距。

## 组件族

- `GameButton`：主按钮、次按钮、危险按钮、禁用按钮四种语义；封面桌面版额外使用 PNG 默认/橙色悬停/按压状态。
- `StatusMeter`：生命、饥饿、耐久、群体饥饿四种语义。
- `CommandPanel`：桌面行动分组与手机操作页共用数据源。
- `NarrativePage`：剧情、探索事件、教程、历史、鸣谢和结局共用可滚动正文。
- `ChoiceList`：配置驱动的可用、锁定和选中状态。
- `DashboardNavigationChrome`：按设备位置、游戏模式与旧存档恢复状态统一筛选标题栏和底栏入口。
- `BottomNavigation`：在手机和紧凑布局显示，入口数量由配置中的位置与模式白名单决定。

## 动效与性能

页面只使用短距离淡入与位移，封面采用极慢的镜头漂移。系统开启“减少动态效果”时停用非必要动效。标签页失焦后切换 LayaAir 慢帧模式；没有角色物理与实时战斗循环，领域状态只在用户操作时结算。

## 资产边界

这是文字剧情游戏，没有角色移动、碰撞、地形或拾取物，因此无需伪造角色精灵和瓦片。现有正式封面和三张菜单 PNG 承担场景与入口美术，HUD、按钮文字、状态条和全部交互文字保持代码原生。后续若增加伙伴立绘或章节场景，应按独立可替换资源接入，不改变领域逻辑。
